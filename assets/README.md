# Brand asset provenance

The README hero is a responsive, text-outlined SVG pair designed for this repository.

## Assets

1. `executive-operator.svg`, desktop, 1600 by 680
2. `executive-operator-mobile.svg`, mobile, 760 by 800

The artwork contains no remote resources, scripts, raster images, gradients, interface mockups, or embedded font files. All visible typography is converted to vector paths so rendering does not depend on the viewer's installed fonts.

## Type source

The outlined letterforms were generated from Archivo Variable by Omnibus-Type at commit `211127690e8ff106c36c935f7e5e697114cff103`.

Font file SHA-256: `664bbeb10522dac35c174a3860aaecad7b1ad3a0fc8b0d26888e26c824ec556d`

Archivo is distributed under the SIL Open Font License 1.1. Source: https://github.com/Omnibus-Type/Archivo

The font binary is not included in this repository.

## Accessibility and delivery

Both SVGs retain `<title>` and `<desc>` metadata. The README uses `<picture>` so mobile does not receive a scaled desktop composition. The product name and explanation also remain ordinary searchable README text outside the image.
