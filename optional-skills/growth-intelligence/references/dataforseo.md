# DataForSEO Reference Adapter

DataForSEO is one optional provider for keyword, search result, local, content, backlink, and related market data. It is not required by the growth skill.

## Use when

1. Search volume and cost estimates matter.
2. Result page structure needs an API source.
3. Geographic keyword demand needs comparison.
4. Local or business data needs enrichment.
5. A repeatable search research workflow justifies API cost.

## Onboarding

1. Confirm the provider account and billing owner.
2. Select the exact APIs needed.
3. Set request and monthly cost limits.
4. Define location, language, device, and search engine defaults.
5. Define freshness and caching.
6. Define prohibited automated uses.
7. Store credentials through the secure path.

## Request contract

Every result retains:

1. Provider endpoint
2. Query
3. Location and language
4. Device and search engine
5. Retrieval time
6. Cost when available
7. Result completeness
8. Provider warnings
9. Raw response pointer when retention permits

## Interpretation

Provider volume, cost, competition, backlink, and traffic fields are estimates. Keep them labeled. A historical API result does not prove present search result order or domain availability.

Use live browsing or another approved source when the decision requires visual result inspection or current page content.

## Verification

1. Authentication succeeds.
2. One known keyword request returns the intended geography.
3. Cost guard stops an over-limit request.
4. Cache does not cross clients or markets.
5. Retry does not duplicate a paid asynchronous job.
6. Provider error produces no invented number.
7. A report names source, settings, time, and estimate status.
